Quando os dados de um cartão são roubados, os criminosos costumam fazer primeiro um pagamento pequeno para testar se o cartão funciona e, só depois, compras maiores. Quem recebe um aviso a cada movimento dá conta logo do primeiro pagamento estranho e pode bloquear o cartão a tempo.

Esta semana, a Visa confirmou um ataque informático a um fornecedor na região Ásia-Pacífico. A empresa garante que os cartões não foram afectados, mas casos como este são um bom lembrete para ter os alertas ligados.

## Como fazer

- **Na aplicação do seu banco**, procure as opções de notificações ou alertas e active o aviso para todos os movimentos do cartão, incluindo compras online.
- **Confirme que o número de telemóvel associado à conta está actualizado**, para receber os SMS do banco.
- **Leia cada alerta.** Se aparecer um pagamento que não reconhece, mesmo de valor muito baixo, bloqueie o cartão na aplicação ou ligue para o número oficial do banco, que está no verso do cartão.
- **Para compras na internet, prefira um cartão com limite baixo** ou um cartão virtual, quando o banco o permitir.
- **Nunca partilhe o código que o banco envia por SMS**, nem com alguém que diga ser do próprio banco.

Os alertas não impedem o roubo dos dados, mas reduzem muito o tempo que o criminoso tem para usar o cartão.
